# Как подключить базу расходов (Supabase) — 5 шагов, ~10 минут

Пока база не подключена, сайт работает как раньше (демо-данные).
Как только сделаете шаги ниже и пришлёте мне две строчки — расходы станут настоящими.

## Шаг 1. Регистрация
1. Откройте https://supabase.com → **Start your project** → войдите через GitHub
   (у вас уже есть аккаунт kmilishkevich-debug) или по почте.
2. **New project**: название `rodkomitet-1g`, пароль базы — придумайте и сохраните
   (он мне НЕ нужен), регион — Central EU (Frankfurt). Ждать ~2 минуты.

## Шаг 2. Создать таблицы и перенести расходы
1. Слева меню **SQL Editor** → **New query**.
2. Откройте файл `supabase-setup.sql` из папки проекта, скопируйте ВСЁ содержимое,
   вставьте в окно и нажмите **Run**. Должно написать Success.
   Это создаст таблицы, права доступа, хранилище чеков и перенесёт все сентябрьские расходы.

## Шаг 3. Завести 2 аккаунта комитета
1. Слева меню **Authentication** → **Users** → **Add user** → **Create new user**.
2. Первый: ваша почта k.milishkevich@gmail.com + придуманный пароль. Поставьте галочку **Auto Confirm User**.
3. Второй: почта второго члена комитета (Наталья Коваленкова?) + пароль. Тоже Auto Confirm.
   Пароли отдаёте им лично — мне присылать НЕ нужно.

## Шаг 4. Прислать мне два публичных ключа
Слева меню **Project Settings** (шестерёнка) → **API**:
- **Project URL** — строка вида `https://abcdefgh.supabase.co`
- **anon public** ключ — длинная строка на `eyJ...`

Пришлите обе строки мне в чат. Это публичные ключи (они всё равно видны в браузере
любому посетителю сайта), секретный `service_role` ключ присылать НЕ надо.

## Шаг 5. Я вписываю ключи и пушу
Я вставлю их в `lib/supabaseConfig.js`, соберу и выложу. После этого:
- комитет входит по своей почте и паролю, родители — кнопкой без пароля;
- «Добавить расход» открывает настоящую форму с обязательным фото чека;
- расходы, итоги и остаток кассы обновляются у всех сразу.
